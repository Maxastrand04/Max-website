# Max-website

Personal portfolio site. Next.js and TypeScript, built to static files.

## Install

```
npm install
```

## Run locally

```
npm run dev
```

Open http://localhost:3000.

## Test

```
npm test
```

## Lint

```
npm run lint
```

## Build

```
npm run build
```

The static site lands in `out/`, one HTML file per page plus `404.html`.
